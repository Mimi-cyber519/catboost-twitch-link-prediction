# Данные

Скачайте с Kaggle:  
[https://www.kaggle.com/datasets/andreagarritano/twitch-social-networks](https://www.kaggle.com/datasets/andreagarritano/twitch-social-networks)

Файлы:
- `edges.csv` — список подписок
- `target.csv` — профили пользователей  
- `features.json` — теги пользователей

Положите файлы в эту папку `data/`.
